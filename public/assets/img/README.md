# /assets/img/ — Image Asset Directory

Drop real photography and scans here, then set `mediaMode: 'client'` in
`src/config/media.ts` to activate the slots.

## Naming convention

- `factory-workshop-01.jpg` … `factory-workshop-08.jpg`
- `cert-iso9001.jpg`
- `cert-ce.jpg`
- `cert-rohs.jpg`
- `cert-ukca.jpg`
- `og-placeholder.png`
- `wechat-qr-placeholder.png`

While no client files are present, the built-in SVG demo visuals keep every
section rendering without broken-image placeholders.
